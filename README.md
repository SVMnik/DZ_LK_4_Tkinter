# Tkinter GUI Application - User Profile and Welcome Window

## Описание проекта

Проект представляет собой графическое приложение на Python с использованием стандартной библиотеки Tkinter и дополнительных модулей для работы с графикой. Приложение состоит из двух независимых окон:
- **MainWindow** - основное окно приветствия с изображением и анимированным GIF
- **MainWindowProfile** - окно профиля пользователя с информацией о пользователе

## Технологический стек

### Основные технологии

| Компонент | Версия | Назначение |
|-----------|---------|-------------|
| **Python** | 3 | Основной язык программирования |
| **Tkinter** | Стандартная | Библиотека для создания GUI |
| **PIL (Pillow)** | 9 | Библиотека для работы с изображениями |
| **os** | Стандартная | Модуль для работы с файловой системой |

### Компоненты Tkinter

#### Основные виджеты
- **Tk** - главный класс приложения, корневое окно
- **Toplevel** - класс для создания дополнительных окон
- **Label** - виджет для отображения текста и изображений
- **PhotoImage** - класс для работы с изображениями в Tkinter

#### Модули
- **ttk** - themed tkinter, расширенные стилизованные виджеты

### Компоненты Pillow (PIL)
- **Image** - основной класс для работы с изображениями
- **ImageTk** - модуль для совместимости PIL с Tkinter
- **ImageSequence** - итератор для работы с анимированными изображениями

### Классы приложения

#### 1. MainWindow - Основное окно приветствия

**Назначение**: Отображает приветственное сообщение с фоновым изображением и анимированным GIF.

**Функциональность**:
- Установка геометрии окна (960x660 пикселей) с позиционированием
- Отображение текстовой метки приветствия
- Загрузка и отображение фонового изображения JPG
- Загрузка и воспроизведение анимированного GIF с кадровой анимацией
- Обработка ошибок загрузки файлов

**Методы**:
- `initializeUI()` - инициализация интерфейса
- `setUpMainWindow()` - настройка основных элементов
- `animate_gif()` - анимация GIF через циклическую смену кадров

#### 2. MainWindowProfile - Окно профиля пользователя

**Назначение**: Отображает профиль пользователя с персональной информацией.

**Функциональность**:
- Компактный размер окна (250x400 пикселей) с позиционированием
- Отображение аватара пользователя и фонового изображения
- Вывод информации в разделах:
  - Биография
  - Навыки и умения
  - Опыт работы
- Использование различных шрифтов и цветового оформления

**Методы**:
- `initializeUI()` - инициализация интерфейса
- `setUpMainWindow()` - основная настройка окна
- `createImageLabels()` - загрузка и отображение изображений

### Работа с изображениями
**Статические изображения**
```python
self.world_image = ImageTk.PhotoImage(Image.open(image_path))
world_label = tk.Label(self, image=self.world_image)
```
**Анимированные GIF**
```python
self.gif_frames = []
gif = Image.open(gif_path)
for frame in ImageSequence.Iterator(gif):
    frame = frame.resize((100, 100), Image.Resampling.LANCZOS)
    self.gif_frames.append(ImageTk.PhotoImage(frame))
```
**Механизм анимации**
```python
def animate_gif(self):
    self.gif_label.configure(image=self.gif_frames[self.current_frame])
    self.current_frame = (self.current_frame + 1) % len(self.gif_frames)
    self.after(100, self.animate_gif)
```
**Система позиционирования:**
Absolute positioning через place(x=, y=)

**Точное расположение элементов по координатам**

**Поддержка z-order через порядок создания элементов**

**Управление ресурсами**
```python
self.images = {}  # Хранение ссылок на изображения
self.images[image] = ImageTk.PhotoImage(Image.open(image))
```
**Сохранение ссылок на изображения для предотвращения сборки мусора**

**Проверка существования файлов через os.path.exists()**
